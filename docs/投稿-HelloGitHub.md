## 推荐项目

**项目地址**：https://github.com/ZhongQuinnKing/yuchi

**类别**：人工智能

**项目标题**：玉尺：给中文写作量呼吸的一把尺，文章与诗都能量

**项目描述**：

玉尺是一个中文写作诊断工具，量的是节奏：贴一段文字，它把读起来不顺的地方量成数、指到句子——句子的长短有没有起伏、套话和连接词是不是超了、段落是推进式还是清单式，给出分数（有气 / 气弱 / 气滞 / 无气）和落到具体句子的改法。诗另有一套体检：逐字平仄标注与读感解释（“连着四个仄声，念起来发紧”）、近体诗格律检查、偶句韵脚查对（平水韵）；词可对 818 个词牌逐字对谱（词林正韵）。

**亮点**：

- 三个入口同一套算法：命令行（Python 纯标准库，零依赖）、单文件网页（打开即用）、AI 技能包（含十四篇写作教材，装进 Claude、豆包等助手，让 AI 写中文时按规矩办）
- 阈值是校出来的，不是拍脑袋：满分点按真人语料 75 分位标定，分数附带“约超过多少人类样本”的百分位
- 双端一致性较真：命令行与网页两个分析器逐样本硬比对，跑在 CI 里；发布前过五道门禁（内容自检 / 校对 / 双端比对 / 隐私扫描）
- 数据全开源：平仄表与韵书来自开源项目（MIT）、词谱随仓库入库（818 牌）；校准的验过什么、没验过什么，如实写在仓库 CHANGELOG 里

**示例代码**：

```bash
git clone https://github.com/ZhongQuinnKing/yuchi && cd yuchi
python3 yuchi.py 你的文章.txt          # 文章诊断
python3 yuchi.py 你的诗.txt --poem     # 诗：平仄标注 + 韵脚
python3 yuchi.py 词.txt --ci 忆江南    # 词：逐字对谱
```
