## 快速使用

**项目地址**：https://github.com/ZhongQuinnKing/yuchi
**网页版（免安装）**：https://zhongquinnking.github.io/yuchi

```bash
git clone https://github.com/ZhongQuinnKing/yuchi
python3 yuchi.py 你的文章.txt          # 文章诊断
python3 yuchi.py 你的诗.txt --poem     # 诗：平仄标注 + 韵脚
```

## 项目介绍

玉尺是一个中文写作的诊断工具。它不查错别字，也不查语法，量的是更玄但更关键的东西——节奏。一段文字读起来顺不顺，很多时候不在用词，在句子的长短呼吸、连接词的分量、段落是推进还是平铺。

玉尺把这些量成数：总分（附“约超过多少人类样本”的百分位）、逐层拆解（大句呼吸 / 句内呼吸 / 套话与虚词 / 段落参差）、问题指到具体句子并附改法。满分点不是拍脑袋定的，按真人语料 75 分位标定。

诗另有一套体检。近体诗：逐字平仄标注、“连着四个仄声，念起来发紧”式的读感解释、偶句韵脚查对平水韵；词：818 个词牌逐字对谱、词林正韵查韵；对联：字数、平仄、对仗逐位校验——尺子只报数，判断留给你。

三个入口同一套算法：命令行（Python 纯标准库，零依赖）、单文件网页、AI 技能包（十四篇写作教材，从节奏、结构、改稿流程到诗的呼吸、工具地图，装进 Claude、豆包等助手，AI 写中文时按它办）。

## 几个落点

- 写公众号、文案、报告：贴进去，它指出哪几句“平”了、哪个词是套话，改完复量一遍
- 写诗：平仄标出来、韵脚查对韵部；“景到诗”引导从眼前的景走到一首诗，给起点不给终点
- 用 AI 写东西：技能包装进助手，让它下笔时带着呼吸；写完再过一遍尺
