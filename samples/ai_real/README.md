2026-10-09 用本机模型生成。普通用户口吻，prompt 只有「请写…。直接输出正文。」
- `r_01` 到 `r_10`：通用文章（散文/记叙/议论/书评/文案等），模型 A
- `c_01` 到 `c_10`：同题通用文章，**模型 B**（换模型：`YUCHI_SAMPLE_MODEL=deepseek-chat python3 make_real_ai_samples.py general c_`）——两模型结果高度一致（中位 71 / 70）
- `o_01` 到 `o_10`：事务与限定文体（工作总结/通知/道歉信/JD/会议纪要等）

用途：玉尺校准的真实侧复验——构造样本（`samples/ai_gen/`）证明
「典型腔特征」可被识别，这两组真实样本回答「真实模型写的会落在哪」。

  不是作者身份
- 事务组 8/10 被判为条目/结构化文本（按文体分流，不打散文分，
