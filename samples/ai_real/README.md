# 真实 AI 输出样本（10 篇）

2026-10-09 用本机模型生成。普通用户口吻：10 个通用主题，prompt 只有
「请写一篇 800 字左右的中文文章，主题：X。直接输出正文。」

用途：玉尺校准的真实侧复验（v1.1）——构造样本（`samples/ai_gen/`）证明
「典型腔特征」可被识别，这组真实样本回答「真实模型写的会落在哪」。
结果：真实 AI 60 到 91 分（中位 76），与人类语料中位持平；
被压低的是典型腔特征，不是作者身份。详见 CHANGELOG v1.1 与
`references/07-验证与依据.md`。

生成脚本：`make_real_ai_samples.py`（复现需自备模型端点）。
内容为通用主题写作，无隐私信息。任何模型的输出都可以用同一把尺复量。
