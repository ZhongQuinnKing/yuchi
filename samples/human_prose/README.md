用途：玉尺的人类参照语料。原校准语料（`samples/human/`）以工具性文本为主，
这一批补上“纯散文”参照：本目录 54 段 ＋ 原语料里的散文型 11 段 ＝ 65 段，
`PERCENTILE_TABLE`（分数→百分位参照表，命令行与网页各一份）按这 65 段重标。

**语料纪律（2026-10-09 立）**：公版≠可用——抓取时逐条审内容，政治、革命、
民族议题的文献（如同一批抓到的瞿秋白政论与《国际歌》译文、闻一多《七子之歌》）
一律不取，只留纯文学与文艺理论；越线篇目已撤。

处理约定：按自然段聚合切成 300-800 字的片段；繁体转简体（zhconv）；
每段首行注明来源与版权状态。

存量盘点（2026-10-09 定案）：作者页其余篇目多为红链（文库未收录，如郑振铎《海燕》、
丰子恺全部作品）——公版池到此见底；更近年代与当代语料受版权所限（见
`references/07-验证与依据.md`）。
