# 歌词：担着曲子的字

诗为自己站立，词要担着曲走。同一批汉字法则（节奏、密度、具体、腔调），歌词头顶多一层约束：旋律。

林秋离的比方最省事：旋律是物体，歌词是它的外表。词让曲子的概念明确起来。写词因此比写文章多一道工序，先把耳朵打开。

## 一、两种工序路

先词后曲，词自带旋律感，曲者顺着词的呼吸谱，压力在曲不在词。先曲后词是主流，词服从曲，一个字一个字往旋律的格子里放。《山丘》曲先成、词磨十年；《青花瓷》曲先到、词三易其名。两条路都通，先立者约束后者，这是歌的规矩。

## 二、前置两道

写词之前，先做两件事。

**人物卡**（李宗盛法）。这首歌里谁在说话，在哪儿，对谁说，什么口吻，什么脾性。他自己说：故事里头的主人翁是什么性格脾气、左撇子或右撇子、吃素还是吃荤。人物立住，词才立住。空写情绪，词会飘。

**七感物写**（Pat Pattison 法）。围着核心物象，用七个感官写十分钟意识流：视、听、嗅、味、触、体内感觉、动觉。不修文法，只管往下写。写完回来挖钻石，把准确有力的短语挑出来，那就是词料。先下潜，别在水面漂。

## 三、咬合四条

词放在曲上，有四条硬律，来自实际创作的验证（三级作曲实践，一词对位核过全程）：

1. **一字一音为主**。长音处放词眼，一个音最多担两个字。挤三个字，唱不清。
2. **句读对齐呼吸**。句子的断点落在乐句的呼吸位，句尾落在终止长音上。词断在曲吸气处，唱者才有地方换气。
3. **语法重音落强拍**。词上的重音，踩在旋律的强拍位（Pattison 重音对位）。叙述体歌可以反用，李宗盛的句尾字常不落拍上，说话感就出来了。规则是工具，不是铁律。
4. **声调不拧**。字的调值与旋律走向别打架，上声去声避开低音折点。倒字是外行的破绽。

字位对不对，可以程序核，一个字对一格，对不上就改词，不改曲（三级有词格核对的先例）。

## 四、结构语汇

歌有歌的零件：前奏、主歌、副歌、尾句。副歌是压舱石，一句立住，全歌立住（"天青色等烟雨"是定稿前反复不舍的一句）。

**预现**：副歌材料提前露头。Max Martin 的做法极端，听完前奏和主歌，整段副歌旋律已经预听过一遍，副歌一到人人会跟。

**叠句变义**：重复句每次出现，意义要变。《山丘》的"喋喋不休"两处两个意思，一自嘲一叹息。同句同位同义，是偷懒。

**名词干活**：每写一个名词，自问一句，它在歌里干什么活。不干活的删掉。方文山的死穴就在这儿，《本草纲目》堆中药名而药性全无，被批了多少年。意象要长成系统，别摆成展览。

## 五、词法六条

1. **首句即题眼**。《山丘》首句磨十年。"想说却还没说的还很多"一句立住，后面全是它的展开。首句不入题，全歌散。
2. **辨识度优先**。喻体选大众认得的。方文山写《青花瓷》曾名《青铜器》，太刚；改《汝窑》，太生僻；定青花瓷，人人认得，线条也合情歌。
3. **画面失真警戒**。只写亲见或查证过的物。写不熟的地域，画面会虚（《牡丹江》的教训）。
4. **动词驱动画面**。静物堆形容词是死的，动词让两物发生关系就活了。芭蕉惹骤雨，一个"惹"字立起半幅画。
5. **白描要准**。辞藻是虚的，准确是实的。写普通人，就用普通人一年的词汇量写准。
6. **升维术**。小念头一级级放大成命运感，涓滴意念汇成河。抒情歌的常用杠杆，用多了也腻，一首歌一次。

## 六、韵

现代歌用宽韵，an、ang 一系可以贯通，韵脚落在乐句的终止长音上。同韵的重复句守叠句变义，义变了才许用。古风词走古典韵书，本技能的 `data/` 里有平水韵、词林正韵、中原音韵三套，`embed_rhyme.py` 可查。

## 七、自检清单（交稿前逐项过）

- [ ] 人物卡在案：谁在说、什么口吻，说得清
- [ ] 咬合四条核过：字位对得上，重音不偏，无倒字
- [ ] 首句是题眼：删掉首句，全歌还成立吗？成立就重写首句
- [ ] 每个名词都干着活：抽查五个名词，说得出它们干什么
- [ ] 副歌一句能当封面：读一遍副歌，记住的是哪句
- [ ] 重复句变义：每处重复问一句，这次和上次的意思一样吗
- [ ] 韵脚落终止：韵字在乐句收束处
- [ ] 唱一遍：拗口处，改词
