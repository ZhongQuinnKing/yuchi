# 玉尺 · 量一量中文的呼吸

> 「仙人持玉尺，度君多少才。」
> ——旧题李白《上清宝鼎诗》（作者有考证争议，《全唐诗》补遗收入李白名下）

把一段文字贴进来，玉尺说出哪里读起来“不像人写的”，指到句子，告诉你怎么改。量的是节奏，不是词表。

玉尺做两件事，同等对待：**把文章写好**，和**把诗写好**。文章与诗不分主次，各求各的领域最强。

*English TL;DR — Yuchi (“jade ruler”) is a rhythm-based diagnostic for Chinese writing: sentence-length breathing, filler and cliché density, structure. It points at the exact sentences that read machine-like and shows how to fix them. Ships as CLI, a web page, and an AI skill pack. Chinese-first.*

## 这是什么

中文写作里，“机器味”从来不是几个词的错。真正的分界在结构：句子的长短起伏、连接词的分量、段落是推进还是平铺。玉尺把那道分界量成数：

- **节奏层**：句长呼吸、句内节奏、平滑段定位
- **密度层**：套话与连接词、破折号、虚词与空夸词
- **结构层**：清单式还是推进式
- **具体层**：形容词有没有落到数字、动作、场面
- **段落层**：段落参差度

量完给三样：分数（有气 / 气弱 / 气滞 / 无气）、问题定位、落到句子的改法。

**作诗方向**（与写作同标准推进）：诗模式已能体检——贴一首诗，看行长呼吸、逐字平仄标注与读感（“连着四个仄声，念起来发紧”这类）；「景到诗」在建设中——把眼前的溪流与蓝天简单描绘，得到合心意的句子；近体诗、词、联、曲、赋各类型按批补齐。

## 三件套

1. **网页版**：打开就能量，贴文字出诊断卡（`web/index.html`，可直接挂 GitHub Pages）
2. **命令行**：`python3 yuchi.py 你的文章.txt`（零依赖，纯标准库）
3. **技能包**：`SKILL.md` 加十二篇教材，装进 Claude、豆包等 AI 助手——AI 写中文、改中文时按它办

## 怎么装

**AI 助手（技能包）**

- 豆包等：对它说一句“请安装这个 skill：https://github.com/ZhongQuinnKing/yuchi”
- Claude Code / Codex：`git clone https://github.com/ZhongQuinnKing/yuchi ~/.claude/skills/yuchi`

**命令行 / 网页**：clone 下来即用，无需安装任何东西。

**给 AI 用户的开口模板**（详见 `references/10-AI协作.md`）：

> 请你写一篇（标题与用途：＿＿）。料（用这些素材，一个字不许编）：＿＿。谱（照着写）：每 200 字至少一句十二个字以内的短句；不许用“首先、其次、最后”串联；不许出现“值得注意的是、综上所述”；破折号全文最多两处；形容词尽量换成数字、动作、例子。样子（语气参考）：＿＿。完事后自查一遍，把没过的项报给我。

## 边界（先说清楚）

- **不测 AI 率，不承诺检测数字**。“检测率”是检测器的输出，玉尺不打这个分，不宣传，也不针对任何检测器做优化。
- **分数是参考**：清单是底线，尺子是尺度，作者是主人。
- **改稿不改事实**：只动结构，数字、人名、日期、引语一个字不动。
- **学术场景**：只教方法、给改法，不代写正文。

## 判断从哪来

写在 `references/07-验证与依据.md` 里：研究结论（句长节奏是最强判别特征，多项研究以句长加标点密度组合达到 96% 至 98% 的准确率）、语料校准（真人语料对 AI 合成腔，满分点按人类语料 p75 标定）、几百年的中文写作传统。工具的已知局限、教材自评口径，那一篇里全摊开。
